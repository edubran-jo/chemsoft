# chemsoft
Software to calculate the volume of reactors depending on given project specifications.

Built totally in PT-BR.

Created as a Undergraduate Thesis for Bachelor's Degree in Chemical Engineering. The program uses concepts acquired during the course and apply those concepts to calculate the volume of a reactor based on desired specifications.

Based off of previous knowledge, the software is simple on how to use it:

1) Open the software
2) Select desired reactor
3) Input project specifications:
4) View the results and/or plot graphs to view tendencies.

   OBS: the software was designed with specific reactions in mind, bear in mind that IT'S NOT COMPREHENSIVE and it lacks fine tuning, as in adding more reactions. For the purposes of a Thesis, I coded the necessary reactions and built the software.

   It is possible to continue adding more reactions to make it more comprehensive, so it's still a living project.

The project was created using Python, with the matplotlib, for graph building, numpy, for more complex calculus, and TKinter for UI.
